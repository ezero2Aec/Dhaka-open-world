# Android Build Instructions (Termux)

## Prerequisites
- Termux installed on an Android device.
- Android SDK (platforms/android-34) installed at `$HOME/android-sdk`.
- Ant (`apt install ant`).
- Java 8 JDK (`apt install openjdk-8-jdk`).
- `aapt2`, `d8`, and `apksigner` binaries available in `$PREFIX/bin` (installed via Termux packages).
- Debug keystore at `$HOME/.android/debug.keystore` (default generated by Android tools).

## Repository layout
```
app/
  AndroidManifest.xml            # Package ID: com.example.dhaka
  build.xml                    # Ant build script (see below)
  src/main/java/com/example/dhaka/   # Java source files
  src/main/res/                # Resources (layouts, values)
```

## Build steps
1. **Open Termux** and navigate to the repository root.
   ```bash
   cd $HOME/dhaka-open-world-github-clean/app
   ```
2. **Run Ant** to compile, dex, package, and sign the APK.
   ```bash
   ant debug
   ```
   - The script uses the following properties (defined in `build.xml`):
     - `sdk.dir` – Android SDK location (`/data/data/com.termux/files/home/android-sdk`).
     - `keystore.path` – Debug keystore (`/data/data/com.termux/files/home/.android/debug.keystore`).
     - `aapt2`, `d8`, `apksigner` – Expected to be in `$PREFIX/bin`.
   - Output APK will be placed at:
     ```
     app/build/apk/app-debug.apk
     ```
3. **Verify the APK** (size, checksum). Example:
   ```bash
   ls -l app/build/apk/app-debug.apk
   sha256sum app/build/apk/app-debug.apk
   ```
4. **Install on a device** (USB debugging enabled) using `adb`:
   ```bash
   adb install -r app/build/apk/app-debug.apk
   ```
   - If `adb` is not installed, you can copy the APK to the device storage and install via the file manager.

## Common issues
- **Missing SDK platforms**: Ensure `platforms/android-34` exists under `$SDK_DIR`. Install via `sdkmanager` if needed.
- **`aapt2` not found**: Install `aapt2` package (`pkg install aapt2`).
- **`d8` not found**: Install `d8` (`pkg install d8`).
- **`apksigner` not found**: Install `apksigner` (`pkg install apksigner`).
- **Java version**: Ant expects Java 8; newer JDKs may cause warnings. Use OpenJDK 8 from Termux.

## Reproducibility
Running `ant debug` on any fresh checkout with the above prerequisites yields a signed debug APK ready for installation. No Gradle, no external Linux distro, and no additional tooling are required.
