# Mandatory Agent Startup Instructions

Read every file in the context directory before development.

Do not stop after producing a plan.

Execute these tasks:

1. Inspect the project directory.
2. Inspect the available Android development tools.
3. Inspect GitHub authentication without exposing credentials.
4. Choose a suitable Gradle-free Android game development pipeline.
5. Verify that the pipeline can actually produce an APK.
6. Create the GitHub repository if it does not exist.
7. Build a minimal playable Dhaka-inspired game.
8. Build and test the APK.
9. Commit and push the source code.
10. Publish the APK through the repository or GitHub Releases.

Do not fabricate build results, repository URLs or download links.

If a requirement is blocked, diagnose the actual technical issue and continue with everything else that can be completed.
