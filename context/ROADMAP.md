# Development Roadmap

## Phase 1 — Engine and Build Pipeline
- Inspect Termux and Android SDK availability.
- Select a suitable 3D engine.
- Verify Gradle-free Android export.
- Configure the Android build environment.
- Produce a minimal test APK.

## Phase 2 — Playable MVP
- Create a Dhaka-inspired neighborhood.
- Implement third-person movement.
- Implement camera controls.
- Add one vehicle.
- Implement driving and entering/exiting vehicles.
- Add touchscreen controls.

## Phase 3 — City Simulation
- Traffic AI.
- Pedestrian AI.
- Buildings and shops.
- Dhaka-inspired streets.
- Rickshaws, buses and CNG vehicles.

## Phase 4 — Gameplay
- Missions.
- Interaction system.
- Save/load.
- Audio and effects.

## Phase 5 — Android Release
- Optimize performance.
- Configure package identifier.
- Create application icon.
- Build release APK.
- Sign APK.
- Test installation on Android.
- Record APK size and SHA-256 checksum.

## Phase 6 — GitHub Publication
- Create GitHub repository.
- Push complete source code.
- Publish APK.
- Create release notes.
- Document installation instructions.
